Graphify

Biến codebase + tài liệu thành knowledge graph có thể query được

Nguồn: github.com/Graphify-Labs/graphify — Apache-2.0 License, Python, uv-managed, ~133.7k stars, 12.8k forks (số liệu 23/10/2026)

Graphify là tool chuyển đổi codebase (bao gồm code, docs, SQL schemas, configs, PDFs, images, video/audio) thành knowledge graph có thể query. Thay vì đọc raw files (tốn token), agent query graph (ít token hơn nhiều lần). Tích hợp với các AI coding assistant như Claude Code, Cursor, Codex, Gemini CLI dưới dạng skill /graphify.

Tư duy cốt lõi Graph-first, no embeddings — kết quả là traversable graph JSON, không phải vector store. Query hoạt động qua graph traversal, không phải semantic similarity search. Code extraction chạy hoàn toàn offline bằng tree-sitter AST, deterministic và tái lập được.

Tư duy cốt lõi

1. Deterministic over probabilistic

Code được parse bằng tree-sitter AST thuần túy — không có LLM, không có gì rời khỏi máy. LLM chỉ được dùng cho docs/media bên ngoài codebase. Kết quả hoàn toàn deterministic và tái lập được.

2. Graph-first, no embeddings

Kết quả là traversable graph JSON, không phải vector store. Query hoạt động qua graph traversal, không phải semantic similarity search. Điều này cho phép truy vấn chính xác theo relationships thay vì dựa vào "similarity".

3. Offline-first, modular backends

Code extraction chạy offline hoàn toàn. LLM backends là optional và pluggable — có thể dùng local Ollama, cloud APIs, hoặc IDE context inheritance từ Claude Code/Cursor/Gemini CLI.

4. Transparency qua confidence labels

Tất cả relationships đều được gán confidence label (EXTRACTED / INFERRED / AMBIGUOUS) — graph không che giấu mức độ chắc chắn. Developer biết chính xác đâu là thông tin tường minh từ source, đâu là suy luận của tool.

Pipeline tổng thể

detect() → extract() → build_graph() → cluster() → analyze() → report() → export()

Giao tiếp giữa các module qua plain Python dicts và NetworkX graphs. Không có shared state. Side effects giới hạn trong thư mục graphify-out/.

Edge labeling system

Mọi relationship trong graph đều được gán confidence label — đây là điểm khác biệt quan trọng so với các tool khác.

LabelÝ nghĩaVí dụ
EXTRACTEDRelationship được nêu tường minh trong sourceimport statement, direct function call, class inheritance
INFERREDSuy luận hợp lý từ call-graph second pass, co-occurrenceIndirect dependencies, shared resource usage
AMBIGUOUSKhông chắc chắn, flag cho human reviewDynamic dispatch, reflection, metaprogramming

Relationship types được extract

  • calls — function/method calls
  • imports — module/package imports
  • inherits — class inheritance
  • mixes_in — mixin patterns
  • references — symbol references

Với --mode deep: kích hoạt aggressive INFERRED edge extraction, tìm thêm nhiều relationships hơn nhưng có thể có false positives.

Community detection

Graphify sử dụng thuật toán Leiden (via graspologic.partition.leiden) để tự động nhóm các concepts liên quan thành communities/subsystems.

Quy trình clustering

  1. Xử lý isolated nodes riêng (Leiden bỏ qua chúng)
  2. Chạy leiden() trên connected component
  3. Split các community quá lớn qua recursive pass
  4. Sắp xếp communities theo size giảm dần (deterministic output)

Configuration parameters

  • _MAX_COMMUNITY_FRACTION = 0.25 — Community vượt 25% tổng nodes → trigger splitting
  • _MIN_SPLIT_SIZE = 10 — Số nodes tối thiểu cần có để split

Cohesion score

Mỗi community được tính cohesion score = actual_edges / (n*(n-1)/2) — tỷ lệ cạnh thực tế so với cạnh tối đa có thể. Score cao = community chặt chẽ.

Lưu ý Leiden clustering chỉ hoạt động với Python < 3.13. Dùng --no-label để skip community detection nếu cần.

CLI commands

Build graph

# Run trên current directory
/graphify .

# Run trên folder cụ thể
/graphify ./src

# Deep mode - aggressive INFERRED edge extraction
/graphify . --mode deep

# Update chỉ changed files
/graphify . --update

# Auto-sync khi files thay đổi
/graphify . --watch

Query graph

# Query bằng natural language
graphify query "what connects auth to database?"

# Tìm path giữa 2 nodes
graphify path UserService DatabasePool

# Giải thích concept
graphify explain RateLimiter

Ingest external content

# Fetch paper/tweet, save, update graph
graphify add [URL]

Export options

# Build agent-crawlable wiki
/graphify . --wiki

# Export graph.svg
/graphify . --svg

# Export cho Gephi/yEd
/graphify . --graphml

# Generate cypher.txt cho Neo4j
/graphify . --neo4j

Git integration

# Install post-commit hook tự rebuild graph
graphify hook install

# Start MCP stdio server
/graphify . --mcp

query_graph scoring formula

score = sum(1 for t in terms if t in label) + sum(0.5 for t in terms if t in source)

Start traversal từ top 3 matches. Output truncated tại character budget (~4 chars/token).

Traversal algorithms

  • BFS — breadth-first, frontier expansion per depth level
  • DFS — depth-first, stack-based node/depth tracking

Extraction output schema

{
  "nodes": [
    {
      "id": "unique_string",
      "label": "human readable name",
      "source_file": "path/to/file",
      "source_location": "L42"
    }
  ],
  "edges": [
    {
      "source": "id_a",
      "target": "id_b",
      "relation": "calls|imports|uses|...",
      "confidence": "EXTRACTED|INFERRED|AMBIGUOUS"
    }
  ]
}

validate.py enforce schema trước khi build_graph() tiêu thụ. Rationale nodes (inline comments # NOTE:, # WHY:) trở thành first-class nodes liên kết với source code.

Output artifacts

graphify-out/
├── graph.html       — Interactive visualization (vis.js); click, search, filter by community
├── obsidian/        — Vault format cho Obsidian
├── wiki/            — Wikipedia-style articles cho agent navigation
├── GRAPH_REPORT.md  — God nodes, surprising connections, suggested questions
├── graph.json       — Persistent graph (node_link_graph format) cho future queries
└── cache/           — SHA256-based cache cho incremental processing

GRAPH_REPORT.md nội dung

  • God nodes — highest-degree concepts (central hubs trong codebase)
  • Surprising connections — ranked by composite score; code-paper edges ưu tiên hơn code-code pairs; kèm plain-language reasoning
  • Suggested questions — 4-5 queries mà graph có thể trả lời
  • AMBIGUOUS edges — flagged cho human review

Configuration constraints

  • Graph size cap: 512 MiB (override: GRAPHIFY_MAX_GRAPH_BYTES)
  • Parallel AST parsing: configurable thread pool (GRAPHIFY_MAX_WORKERS)
  • Output token ceiling: 4096 default, configurable lên 32768 cho dense files

Privacy & Compliance

  • Không có telemetry, usage tracking, analytics
  • Code extraction stays local
  • LLM calls chỉ cho docs/media, route qua user-configured backends
  • Query logging: ~/.cache/graphify-queries.log — disabled by default, opt-in qua GRAPHIFY_QUERY_LOG_ENABLE

Auto-sync behavior
  • Code files (--watch): trigger instant rebuild (AST only, không dùng LLM)
  • Doc/image changes: notify user để chạy --update (cần LLM processing)
Thiết kế cho multi-agent parallel workflows.
Structural vs Semantic understanding Graphify tập trung vào structural understanding (cấu trúc code, relationships giữa entities). Với câu hỏi về semantic understanding (business logic cụ thể, ý nghĩa của code), vẫn cần đọc code trực tiếp.
